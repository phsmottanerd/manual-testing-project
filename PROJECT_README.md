# Manual Testing Project - QA Starter Kit

Use este projeto como um portfólio de testes manuais. Ele contém:
- Plano de testes
- Casos de teste (CSV + Markdown)
- Modelo de bug report
- Pasta para evidências
- Exemplo opcionais de automação com JUnit5 + Selenium

**Como usar:**
1. Faça download ou clone o repositório.
2. Abra no IntelliJ (se quiser rodar os testes automatizados, importe como Maven).
3. Preencha a pasta `evidence/` com screenshots dos seus testes manuais.
4. Suba o repositório no seu GitHub e compartilhe o link no LinkedIn.
