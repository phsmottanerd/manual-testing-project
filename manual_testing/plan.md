# Plano de Testes — Aplicação Exemplo (Formulário de Contato)

**Escopo:** páginas de formulário do site de exemplo (DemoQA - Text Box).  
**Objetivo:** validar funcionalidade de cadastro (preenchimento e submissão do formulário) e tratamento de entradas inválidas.

**Ambiente de teste:**
- Navegador: Chrome (versão compatível)
- URL: https://demoqa.com/text-box
- Pré-condições: conexão com internet, navegador atualizado

**Critérios de aceitação:**
- Campos obrigatórios validados
- Submissão apresenta dados no painel de saída
- Mensagens de erro (quando aplicável) exibidas corretamente

**Riscos:** Mudanças no site exemplo (seletor/IDs), instabilidade da página pública.
