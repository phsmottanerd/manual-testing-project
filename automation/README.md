# Automation (opcional)
Nesta pasta há um exemplo simples de testes com JUnit5 + Selenium (Java).

Para rodar:
1. Abra o projeto como Maven (pom.xml está na raiz).
2. Execute `mvn test` ou rode as classes de teste no IntelliJ.
3. O WebDriverManager fará o download do ChromeDriver automaticamente.

(Os testes de Selenium estão comentados por padrão; descomente se quiser executar)
