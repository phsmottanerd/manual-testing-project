# Projeto de Testes Manuais - QA Starter Kit

Este repositório é um **projeto completo de testes manuais** pensado para quem está começando em QA. 
Você pode usar este projeto como portfólio no GitHub e referenciar no seu LinkedIn.

Conteúdo:
- Plano de Testes (manual_testing/plan.md)
- Casos de Teste (manual_testing/test_cases.csv e test_cases.md)
- Modelo de Reporte de Bug (manual_testing/bug_report_template.md)
- Evidências / Screenshots (evidence/)
- README com instruções para usar e adaptar o projeto
- Exemplo simples de automação (optional) em `automation/` com JUnit5 (Java) — opcional
- Licença MIT

Use este projeto para demonstrar que você sabe: planejar testes, escrever casos, reportar bugs e (se quiser) automatizar alguns casos.
