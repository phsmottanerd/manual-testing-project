## 📂 Conteúdo do projeto

- **manual_testing/**: Plano de testes e casos de teste (CSV + Markdown)  
- **evidence/**: Evidências / screenshots dos testes manuais  
- **automation/**: Exemplos simples de automação com JUnit5 + Selenium  
- **README.md**: Este arquivo

## 🎯 Objetivo do Projeto
Demonstrar habilidades em **QA**, incluindo:

- Planejamento de testes  
- Escrita de casos de teste  
- Registro de bugs  
- Execução de testes manuais  
- Automação básica de testes com JUnit5 e Selenium  
- Simulação de objetos com Mockito
